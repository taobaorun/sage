# 调用示例

## 只规划，不生图

```text
Use $illustration 先不要生图。分析这篇文章哪里值得配图，给我 5 张左右的 shot list。每张写清楚放置位置、核心意思、构图类型、AD 的动作和建议短标注。

<文章正文>
```

## 直接生成一组正文配图

```text
Use $illustration 为下面这篇文章生成 4 张 AD 正文配图。保持白底、16:9、轻手绘、留白充足，每张只讲一个观点。

<文章正文>
```

## 为单个概念生成一张图

```text
Use $illustration 把“上下文不是越多越好，而是要在正确时刻送到正确的人手里”画成一张正文配图。让 AD 亲自完成最关键的动作，不要画成正式流程图。
```

## 编辑现有图片

```text
Use $illustration 修复这张图里的 AD，让角色与标准参考图一致；其他构图、文字和白底保持不变。
```

```text
Use $illustration 删除左上角的“系统流程图”，其他内容不要动。
```
