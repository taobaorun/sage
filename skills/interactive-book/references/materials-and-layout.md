# 材质与布局

## 先看比例，再加细节

封面、书脊、纸堆、打开的跨页应形成可信厚度与铰链关系。桌面或衬垫按打开后的书和相机画幅构图，不能仅按合上的封面尺寸确定。

清爽不等于删除所有解释。先减少重复的书外标题、封面副标题和常驻说明，再把长文移到展开区。用户指定删除的文字按范围删，不顺带移除书名或必要操作入口。

## 毛玻璃需要真正透出背景

只加 `backdrop-filter`、但底色接近不透明，会得到发白的塑料面板。多层底色和渐变的透明度会叠加：两个近似均匀层的合成 alpha 为 `1 - (1-a)(1-b)`，不能只看最底层。

可用作调试起点，而不是设计标准：

| 用途 | 底色 alpha | 模糊半径 |
| --- | --- | --- |
| 简短底部导航 | 约 .20–.35 | 约 8–14px |
| 长文阅读区 | 约 .60–.80 | 约 20–28px |

配细亮边、轻内高光和克制外阴影。不要把整个元素的 `opacity` 降低，否则文字也变淡。夜间、低对比背景和小字号分别检查；可读性优先于最低透明度。

验证玻璃时让有颜色或纹理的对象真实位于其后，观察是否能透出模糊色块。若背景几何不在面板后面，再降低 alpha 也无法显出它；不要为伪造透视而改变书的位置。

为不支持 backdrop-filter 和减少透明效果偏好提供不透明回退。CSS 叠层顺序要让回退覆盖主题和展开状态。

## 纸面与阅读面板

纸页纹理在生成或内容变化时重画；分辨率按目标清晰度和 GPU 预算选择。长文字优先使用 DOM 阅读区，提供可选择文本、语义结构和键盘交互；不要只把内容画进 Canvas。

非模态阅读区通常包含一个固定标题行和可滚动正文。正文、零件目录、来源可共享面板的不同模式，避免堆叠多个弹窗。展开状态、当前模式、当前章节要明确。

在窄屏中测量阅读区实际占用高度，为场景留出空间，再更新相机。不要假定某个固定像素高度适用于所有字体和设备。验证安全区、短屏横屏、长标题与滚动。

关闭时恢复到当前仍存在的入口；若入口已重渲染，用稳定 ID 重新查找。目录和实验控件要有语义标签、焦点样式及触控尺寸。Canvas 失效时保留可读内容，隐藏或禁用无法生效的模型操作。

## 毛毡是一种可选材质

需要毛毡或软垫时，静态程序纹理适合生成细短纤维：用固定随机种子、微弱颜色变化、浅 bump、较高粗糙度与柔和 sheen。随机方向的短纤维比规则棋盘更接近毛毡。边缘可用少量线段柔化，不必用昂贵的多层毛壳。

纹理可平铺，重复次数随物理尺寸增加，保持纤维尺度；改长垫子时同步更新接触阴影范围与圆角，不把纹理拉伸成条纹。不要每帧重画噪声。

这些方法来自汽车书的桌垫迭代；颜色、尺寸和是否需要桌垫都由新主题决定。图像生成只用于确实需要的位图资产，程序材质不必经过生图工具。

## 阴影闪烁排查

1. 复查首次加载、相机缓动、静止、窄屏和远距离，区分真的逐帧变化与纹理噪声、截屏压缩。
2. 查桌面、接触阴影、垫子底面的高度间隔；接近共面会受深度精度影响。不能仅凭代码风险就声称已经复现根因。
3. 单变量测试：先增加合理的几何间隔，再评估小幅固定 polygon offset。阴影保持 depth test，通常关闭 depth write；不要靠关闭深度测试把阴影画到书上。
4. 若使用 polygon offset，检查掠视角。斜率系数过大可能把阴影推到垫面前；固定 units 偏移也需按当前尺度与设备验证，不把某个负值当万能解。
5. 检查静态接触阴影与薄实体动态投影是否重复；必要时只停用垫子投影，保留其接收书本阴影的能力。不要冻结全局 shadow map，运行中的模型仍需要更新。

数值验证应比较同一屏幕射线上的表面深度，而不是同一世界 x/z 坐标垂直移动后的投影差。数值间隔只说明几何条件改善，不等于所有 GPU 都已消除抖动。
