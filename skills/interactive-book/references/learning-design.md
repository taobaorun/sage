# 教学与内容

## 给每个实验一个可回答的问题

为跨页准备最小教学记录，形式不限，不要求另建文档：

| 字段 | 要解决的问题 |
| --- | --- |
| 学习目标 | 操作后读者能预测什么？ |
| 条件 | 哪些量固定，哪些量可以改变？ |
| 操作 | 拖动、切换、拆解或装配中的哪一步最有意义？ |
| 反馈 | 形态、方向、速度、数值如何同时变化？ |
| 对照 | 如何只改变一个条件来解释原因？ |
| 解释 | 用什么短句把观察连接到原理？ |
| 适用范围 | 理想化假设、数据来源和未模拟部分是什么？ |

“能拖动模型”只是观察能力；“改变变量并看到因果结果”才构成实验。不要给每章堆同一组滑块，也不要为了互动让本应固定的量独立变化。

## 从一次误解倒推设计

汽车案例最初展示了输入/输出转速和传动比，仍未回答“什么时候应该选哪个挡”。后来补上固定车速、驾驶目的、多个候选挡位的对比，才把比值关系连接到选择条件。

可迁移的方法：

1. 确认读者问的是结构、因果关系，还是某个条件下的选择。
2. 因果关系用控制变量实验；选择问题还要明确目标、约束和可比较的候选结果。
3. 区分“改变物理输入”和“改变评价目标”。只改变省电/快速的目标，不应让同一物理配置的计算值凭空改变。
4. 给出一次可验证的预测，让读者操作后检查，而不是只展示正确答案。
5. 必要时从真实场景切到等效原理模型，再提供返回原场景的路径。

不要将案例的车型、挡位数、车速、转速区间迁移到其他产品；也不要假定所有复杂系统都能用一个线性比例解释。

## 计算先于动画

将输入校验、单位换算和关系计算写成纯函数。派生量从计算得到，不与输入独立钳制：选择了比例，再硬截断输出值会破坏比例关系。越界状态应解释、标记或限制输入，而不是伪造输出。

在适用模型中验证维度、方向、边界、守恒或约束。例如：

- 传动：角速度比、旋转方向；慢放倍率只影响展示时间，不改变数值读数。
- 电路：给定拓扑下的电压、电流与功率关系；不要用外观线路代替实际连接。
- 水循环：区分守恒的水量与驱动相变的能量；不要把视觉粒子数量直接当真实降雨量。
- 光学：区分光路示意与实际能量分布；清楚标注示意范围。

需要真实专业数据时使用可核验的一手资料；只能提供教学假设时，在界面可理解的位置说明。不要用权威措辞掩盖简化。

## 三层内容

- 第一层，纸面：核心问题、结论、关系标签、短操作提示。小屏也能把握主旨。
- 第二层，展开阅读：原理、术语、推导、完整解释与资料来源。
- 第三层，按需实验或零件：局部放大、剖面、参数对照、操作步骤。

删除重复标题、品牌描述和无信息的引导词，优先于缩小字号。让纸面与展开正文共用内容源或明确关联，防止两处解释漂移。

## 判断是否理解

用新条件或反例检查迁移：改变一个输入，读者能否预测结果方向；同一结果能否由不同配置产生；某个直觉结论在哪些条件下不成立。

若有测验，反馈应指出原因。可翻开的答案在未揭示时应始终不可见，包含翻页快照和动画过渡；键盘也应能选择和揭示答案。
