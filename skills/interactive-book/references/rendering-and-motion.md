# 渲染与交互

## 空间与状态

书本、装订线、静止纸页、活动纸页、模型折叠容器分清父子关系。模型绕纸面位置收起，而不是绕包围盒中心缩小；桌垫和灯光放在独立场景层，不随书页变换。

将章节选择、导航过渡、模拟运行和相机运动分开管理。用时间增量驱动模拟；转速改变时累计角度，不能每帧用“新速度 × 从启动至今的时间”重算相位，否则会跳变。

暂停应停止模拟时钟，但仍允许操作相机、打开结构和阅读；重置才恢复初态。切换观察方式不暗中重置已停止的运动或压力、装配等状态。后台暂停的恢复要保留用户之前的运行意图。

## 无相交的保守翻页方案

随附 `page-turn.mjs` 的职责仅为时序：

| 阶段 | 立体模型 | 活动页 |
| --- | --- | --- |
| fold | 旧模型从当前展开程度收起 | 隐藏，旧静止页保持 |
| flip | 明确隐藏 | 从装订线转动 |
| land | 继续隐藏 | 已落稳，短暂保持 |
| unfold | 新模型展开 | 隐藏并恢复新静止页 |

示例时间 `.22/.64/.08/.26` 秒不是物理常数。核心不变量是 `pageVisible && modelVisible` 永远不成立。折叠高度很小时也应设 `visible=false`，包括子模型、答案翻盖和悬停提示。

`createPageTurnTimeline({ flip: .8 })` 可覆盖部分时长；创建后复用 `timeline.getPose(elapsedSeconds, direction)`。direction 为 `1` 或 `-1`，fold/flip/unfold 必须大于零，land 可为零。默认实例通过 `getPageTurnPose` 与 `PAGE_TURN_DURATION` 导出。无效 elapsed 从零开始，有限的超时值得到完成态；减少动态效果时直接请求完成态，不把阶段时长全设为零。

从当前状态开始折叠：若用户在展开途中导航，fold 段的 modelScale 应再乘捕获的当前展开程度，避免瞬间跳到全高。降低动态效果模式可直接切到最终状态，但仍执行状态更新、快照释放与焦点恢复。

### 场景接入顺序

1. 为请求分配递增 token，取消旧过渡并明确完成旧 Promise（例如返回 `false`）。
2. 捕获旧/新跨页的独立纸面纹理，不让活动页引用会继续重画的 Canvas。
3. 隐藏真实翻盖；若答案尚未揭示，在快照中烘焙关闭的遮盖图，防止答案闪现。
4. fold 后才显示活动页。正向：正面为旧右页，背面为新左页；反向：正面为新右页，背面为旧左页。示例平面几何的背面需要镜像 U，实际坐标系以可读截图验证。
5. 在活动页遮挡合适的位置更新下面的静止页；unfold 前切换章节和模型。每个异步完成点检查 token。
6. 结束或取消时，将静止页重新绑定持久纹理，清除活动页面贴图引用，释放临时纹理，恢复控制器。

取消策略要处理快速连点、跳章、返回封面和销毁。不要只覆盖 `turn` 变量而留下悬空 Promise、旧引用或过期回调。合书也应先收起模型，再关闭封面。

阶段法解决的是活动页与立体模型的相交；它不自动解决页与页、书脊、封面或模型内部碰撞。要求机械上连续折叠的纸艺时，需要另做铰链和几何约束，不能用隐藏模型冒充已完成物理验证。

## 纸面坐标与命中

`paper-layout.mjs` 的约定：

- 纸面像素原点在左上，x 向右、y 向下；UV 原点在左下。
- 纸页平铺在世界 XZ 平面，装订线为 x=0。
- 左页 x 范围 `[-worldWidth,0]`，右页 `[0,worldWidth]`；深度范围为 `[-worldDepth/2,worldDepth/2]`。
- 几何旋转、UV 翻转或局部原点不同的项目需加适配，不要直接套用。

打印按钮、点击矩形、翻盖大小和铰链位置必须来自同一布局记录。命中链条：屏幕 CSS 坐标 → 归一化设备坐标 → 射线交点 UV → 纸面像素 → 矩形命中。

用 `createPaperLayout({ width, height, worldWidth, worldDepth })` 创建坐标转换器；前两个是纸面像素尺寸，后两个是世界单位。`rectToWorld({ x, y, w, h }, 'left' | 'right')` 返回中心 x/z 及 width/depth；`worldToPaperPoint` 将纸面上的世界点转回像素。矩形和点由布局层提供有限数值；辅助函数不替代用户输入校验。

射线转换使用 Canvas 的实际 CSS 边界；不要重复乘设备像素比。只处理当前可见的祖先链与可交互对象，防止隐藏模型挡住纸面按钮。

页码按跨页计算，与章节序号无关；一章可以有多跨页。`getSpreadPages(0, 2)` 是从第 2 页开始的第一个跨页，返回 2/3；第二个返回 4/5。封面是否占号、前言起始页由当前书决定。

## 相机与资源

导航时回到能容纳翻页轨迹的视角，结束后再聚焦零件。阅读区展开改变 Canvas 尺寸时，协调 resize 与聚焦时序，避免布局刷新覆盖刚设置的相机目标。

纹理、几何、材质、环境贴图应有所有者。每帧只更新变换与数值；不要持续创建几何和纹理。销毁时取消帧循环、断开观察器和监听器，释放共享资源时避免重复处置仍被使用的对象。

最少验证：前后翻页各一次、快速来回、展开中跳章、关闭中重新打开、阅读区展开后聚焦、暂停后切换视图、离开并返回运行章节。
