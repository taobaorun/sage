# 立体交互书

让读者通过“操作—观察—比较—解释”理解一个关系。书是承载知识的空间；模型要回答问题，翻页要维持空间可信度，正文要按需展开。

默认继承汽车书的真实 3D 空间效果：有厚度的书本、同一相机下的纸页和主体、体积光照与接触投影、真实纸面翻动。更换主题不等于降低呈现层级；单张插图卡片加 CSS 翻转不视为等价交付。

## 确定任务

从用户要求、现有项目和给定参考中确认主题、读者、学习目标、需要保真的事实、目标设备与交付方式。已明确的选择沿用，不重复提问。只在缺失信息会改变实现时追问；否则说明合理假设并开始。

- 新书实施：先完成一个有代表性的跨页，覆盖封面进入、一个有效实验、阅读面板和前后翻页，再扩展章节。只做方案时仅规划相应切片，不要求实现书壳。
- 改现有书：沿用书名、状态与内容结构，仅调整指定问题，不重新搭建整个产品。
- 只分析参考或制定方案：给出观察和方案，不自动改代码或发布。
- PDF、静态教材、非书式单个模拟器：使用适合该交付物的流程，不强套本技能。

参考站点用于提取交互原则与视觉关系。检查可见页面及一次真实操作，区分实际观察与对实现的推测；不要把“看起来没穿模”当成完整动画证明。访问失败时保留证据限制，使用用户截图或现有材料继续可独立完成的工作，不绕过访问挑战。

## 制作流程

新书按依赖顺序推进；局部修改只进入受影响的步骤，保留其他已完成的工作。

### 1. 先写学习关系，再安排跨页

每个跨页先确定：读者要回答的问题、可操纵变量、保持不变的条件、可见结果，以及一次预测或比较。不要按零件清单机械拆章。

纸页通常只放一个核心问题、一句结论、少量关键标签和一次操作提示。完整解释、术语、资料放进可展开的阅读区。书外标题、封面标题、页面标题不要重复堆叠。

若用户不理解，不先增加大段文字。检查实验是否缺少条件、目标或对照，例如“保持流量，改变管径”比两个独立速度滑块更能解释关系。

### 2. 分开内容、计算、场景和界面

按项目复杂度组织模块，保留四个可独立修改的边界：

- 内容：章节、学习目标、纸页短文、展开正文、实验说明与来源。
- 计算：单位明确的纯函数，负责变量关系和状态判断。
- 场景：书页、模型、相机、动画与资源生命周期。
- 界面：目录、导航、实验控件、阅读区、焦点与响应式布局。

已有真实 3D 工程优先；新建时默认从随附的 `three-book-starter` 开始，继承已经实现的书本、相机、光照、翻页与阅读界面。其他技术栈可以使用，但需满足视觉基准中的空间能力；不要因“主题简单”“面向儿童”或“要单文件”自动换成二维卡片书。不要为了书的外观引入无用途的后端、账户或数据存储。

几何形状、动画速度、数值读数必须来自同一套计算。示意模型和真实参数明确区分；不得把教学假设说成厂商规格、专业阈值或实际操作建议。

### 3. 先保证翻页与操作可信

保守且可靠的时序是：旧模型收起 → 翻页 → 纸页落稳 → 新模型展开。活动纸页可见时明确隐藏立体模型和翻盖；仅压扁模型不能保证没有残留相交。

跨页编号与章节编号分别显示。纸面文字位置与点击区域共用坐标定义。快速前后切换时采用最新请求，旧动画不得覆盖新状态；结束和取消都释放临时纹理。

模型是否默认运动由教学目标决定。需要观察运动的章节可默认运行，静态结构和手动装配保留静止；暂停、重置、切换视图分别有清楚语义。减少动态效果偏好应得到尊重。

### 4. 让阅读和书共处

延续本案例的体验时，将正文、零件和资料放入同一个非模态阅读面板，展开后仍能看到书。翻页收起面板；窄屏为它预留空间；关闭后焦点回到有效入口。用户明确要求其他阅读方式时，以其选择为准。

保留可触达的目录、前后页、页码和必要模型操作。低频操作再展开，不把所有按钮和解释常驻到画面上。

### 5. 打磨材质并验证

纸面承载阅读，玻璃承载浮层，桌垫承托书。具体颜色、装饰和是否保留桌垫可调整；真实空间、体积、光照、书本主导的构图不能被当成可有可无的装饰。先做出符合视觉基准的一个代表跨页，再扩展章节，最后精调材质。

验证时同时回答两件事：程序是否满足不变量，读者是否能从实验中理解关系。构建通过不能证明不穿模，截图漂亮也不能证明模型算得正确。

## 可复用核心

**先用可运行骨架，再按需取小模块。**

```sh
node <skill-dir>/scripts/create-book.mjs --out <new-project-dir> --title "新书名"
```

[assets/three-book-starter](assets/three-book-starter) 包含真实 3D 书本、体积模型示例、相机与光照、毛毡桌面、浮动玻璃导航、阅读面板和单文件导出。运行与主题替换方法见视觉基准；这才是默认新书起点。

[assets/book-core/page-turn.mjs](assets/book-core/page-turn.mjs) 提供不依赖渲染引擎的四阶段翻页姿态；秒数是起始示例，可按项目调整。

[assets/book-core/paper-layout.mjs](assets/book-core/paper-layout.mjs) 提供参数化的纸面坐标、UV 命中与跨页编号。坐标约定见渲染参考。

两个小模块可单独接入已有场景，但只复制它们不足以复现汽车书效果。模板没有车型、托管身份或第三方图片，依赖版本在其 package.json 中固定。

验证随附模块：

```sh
node <skill-dir>/scripts/check-book-core.mjs
node <skill-dir>/scripts/check-starter.mjs
```

该检查覆盖纯逻辑和负对照；项目还需验证真实模型、渲染层、快速导航和焦点。不要用它替代浏览器检查。

## 交付

交付可运行的项目或用户指定的产物，简述核心实验、验证结果和已知限制。需要发布时使用当前环境支持的托管流程并核对原站身份与访问范围；本技能自身不授予额外发布或访问权限。用户要求本地版本时仅本地交付。

后续请求示例：

- “用 `$interactive-book` 做一本水循环立体书，让我调节热量，看蒸发和降雨如何变化。”
- “把这本电路书的正文放进页内展开面板，保持书和实验可见。”
- “检查这本书连续翻页时的模型穿透，保留现有外观和章节内容。”
